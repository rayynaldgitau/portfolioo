Events Hub Real-Time Discovery Platform

A responsive, data-driven web application engineered to coordinate shared schedules, host dashboards, and volatile attendee RSVP states with low-latency API routes.

ROLE Full-Stack Developer
CONTEXT Production Web Platform
TECH STACK React • Node.js • Express • MySQL
KEY RESULT Sub-100ms API Response

The Concurrency & RSVP Challenge

Coordinating shared social calendars requires instant interface feedback. When hundreds of concurrent users access identical event rosters simultaneously, the application must fetch data efficiently and update view states dynamically without forcing slow page refreshes or stale cache reads.

Full-Stack Architecture & Data Flow

This platform applies a decoupled system approach: React powers dynamic client-side rendering with optimistic updates, while Node.js and Express handle validation, JWT authentication, and MySQL transactional updates.

  • Optimistic UI Updates: Client views update attendance immediately while network requests verify the mutation in the background.
  • Relational Join Indexing: Isolates heavy user-to-event join tables inside MySQL to keep roster lookups under 20ms.
  • Token Authentication Guard: Validates user credentials on every state-altering mutation to eliminate unauthorized schedule edits.

Performance & Web Vitals Impact

Achieved sub-100ms average response times across core RSVP routes and eliminated layout shifts (CLS < 0.05) through skeleton placeholders and fixed card dimensions.
