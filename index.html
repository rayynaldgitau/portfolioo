Desktop File Explorer

Folderly

Visual file explorer and safe bulk-renamer desktop app for macOS and Windows.

Silent 20-second demo showing Folderly's sidebar drives, pinned folders, multi-tab workspace, extra-large file icons, Quick Look preview, and bulk rename toolbar.

Problem It Solves

Default OS file explorers lack safe bulk-renaming previews, scatter quick-look and whole-PC search across separate tools, and expose critical folders to accidental deletion. Folderly pairs fast native Rust filesystem operations with collision detection before disk writes, a 1-click transactional undo ledger, and protected OS directory guards.

Key Features

  • Quick Look (P / Space): Instant preview for images, video, audio waveforms, code, PDFs, and folders.
  • Tabbed Browsing (Ctrl+T / Ctrl+W): Multi-tab workspace with drag-and-drop support.
  • Universal Search (Ctrl+K): Spotlight-style command palette across local drives.
  • Safe Bulk Renamer: Collision detection preview and 1-click transactional undo ledger.
  • Safety & Privacy: Blocks root/system deletion, hardened Tauri v2 CSP, 100% offline with zero telemetry.
